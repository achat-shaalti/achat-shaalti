# שומר מסך — תוסף לאוצריא (חד בדרא)

ענף נפרד לשמירת המקור של התוסף "שומר מסך" (`com.hadbedara.otzaria-screensaver`). לא קשור לבנייה של אחת שאלתי.

- `src/` — המקור (פורס ישירות כ-.otzplugin: `cd src && zip -r ../dist/otzaria-screensaver-X.otzplugin .`)
- `dist/` — קבצים מוכנים להעלאה לחנות (העלאה ידנית).
- עותק מוכן מוצע גם בהתקנת אחת שאלתי: `optional-plugins/otzaria-screensaver.otzplugin` בענף next.

## 1.7.0 (12.11.2026, יציבה) — מעל 1.6.1 שבחנות
- הגדרות: המבנה של 1.6.1 (כרטיס "תצוגה", שתי עמודות).
- תיקון: הסלוגן הופיע בפינה העליונה בסגנונות "ספר נפתח"/"ספר צף".
- צבעים: "אוצריא בהיר" = רקע אוצריא (surfaces.reader או surface; במצב כהה — גוון בהיר של הצבע הראשי); "אוצריא כהה" = הצבע הראשי בגוון כהה (55% לשחור). מתעדכן חי (`events.subscribe:theme.changed` נוסף להרשאות), צבעים בפורמט #AARRGGBB נתמכים.
- ציטוטים (דיווחים מהמייל 10–11.11): בוטלו קטעים אקראיים מספרי התנ"ך בספרייה (יצאו חלקי פסוקים, סימונים ותרגום לאנגלית). רק רשימה נבחרת: 5 בסיס + 18 נוספים (תהילים, משלי, דברים, ישעיהו, קהלת, אבות) על לימוד התורה וניצול הזמן. "ציטוטים נוספים" (quotesLib) מפעיל את הרשימה המורחבת. הסתרת ציטוט הש"ך מורידה אותו גם מהסבב.
- "הלכות": כפתורי התוכן מציגים את הכותרת המלאה (נחתכו), והוסרו המילים באנגלית.
- סגנון חדש: "ספר וציטוטים".
