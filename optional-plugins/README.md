# תוספים מוצעים

תוספים של חד בדרא שאינם חלק מ"אחת שאלתי", ומוצעים בהתקנה (לא חובה):

- `otzaria-screensaver.otzplugin` — **שומר מסך** 1.7.0 (קובץ מוכן, כמו בחנות של חד בדרא; המקור בענף `screensaver`).

איך זה עובד: הגשר מטמיע את הקבצים כמשאב `optional.*`, פורס אותם ל-`%LOCALAPPDATA%\OtzariaBridge\plugins\optional`,
ומתקין אותם באוצריא רק אם המשתמש בחר: במתקין — תיבת הסימון "להתקין גם את התוסף שומר מסך" (`--with-screensaver`);
בהתקנה ידנית (`--install`) — שאלה כן/לא. "התקן/עדכן את התוספים" במגש לא נוגע בתיקייה הזו.

לעדכון: להחליף את הקובץ כאן בגרסה החדשה ולדחוף ל-next.
